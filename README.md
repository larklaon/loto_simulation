# lotto pick

로또 6/45 번호 조합을 생성하는 미니멀한 Next.js 웹 앱입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인할 수 있습니다.

## 주요 기능

- 한 번에 1~5게임 조합 생성
- 최대 5개의 고정 번호 선택
- 생성된 번호 전체 복사
- 모바일 화면 대응

## 배포

Vercel에서 이 저장소를 가져오면 Next.js 프로젝트로 배포할 수 있습니다. 로컬 프로덕션 빌드는 `npm run build`로 확인합니다.
